ModelDock 0.2.0 首次正式提供 Windows 桌面安装包，并加入应用在线更新。

新增：
- 启动后检查稳定版更新，侧栏提示新版本；也可在“应用更新”中手动检查。
- 显示更新说明、下载进度与失败重试，用户点击后才下载、安装并重启。
- 使用 Tauri 更新签名，校验安装包内容和签名绑定的版本；校验失败不会安装。
- 下载前和安装前检查本机任务与插件环境操作，避免在使用中覆盖程序资源。
- 发布安装包、签名、latest.json 更新清单与 SHA256SUMS，并提供可复用发布流程。

包含首版能力：Python 插件及独立 uv 环境、ONNX 分类与检测参考插件、单图/批量/性能测试、结果可视化和报告、SSH Linux 节点。

安装：下载并运行 `ModelDock_0.2.0_x64-setup.exe`。首次准备 Python 和依赖需要联网；模型权重需自行提供。参考插件仍限定 CPU、batch=1 和约定的 ONNX 格式。

0.1.0 试用包尚未包含更新器，首次升级到 0.2.0 需要手动运行安装包。0.2.0 起可从应用内更新后续稳定版。模型、插件环境和测试记录保存在用户数据目录，不随程序安装目录替换。
