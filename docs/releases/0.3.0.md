# ModelDock 0.3.0

- 新增 timm 图像分类插件，提供 209 个预训练配置及模型搜索、家族筛选。
- SDK 0.1.1 新增可选 describe/1 元数据接口，共用清单扩展使用 extensions.modeldock；保留旧插件生命周期并持续维护独立插件协议文档。
- 使用独立且锁定的 PyTorch CPU 环境，支持官方预训练权重及匹配架构的 safetensors、PT/PTH/BIN 张量权重。
- 自动采用模型配置中的图片预处理参数，支持类别数与类别文件检查、Top-K、批量与性能测试；复用现有可视化、历史及导出。
- 导入模型新增 HTTP/HTTPS URL 权重下载，支持进度、取消、重试及可选 SHA-256 校验；SSH 节点可直接下载至远端。
- 官方 timm 权重优先使用 safetensors，缺失时尝试 PyTorch 权重，自动关联 ImageNet-1k 类别文件。下载完成后仍执行加载兼容性检查。
- 下载未结束时阻止安装应用更新，保留已有模型、插件环境及测试记录。

本版 timm 插件仅提供 CPU、batch=1 图像分类；各目录配置须通过加载检查，训练时改变预处理的自定义权重需要匹配配置。现有 ONNX 分类与 YOLO 插件保留原有兼容范围。预训练权重由用户下载，遵循发布方许可，不包含在安装包内。
